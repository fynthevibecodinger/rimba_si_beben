# Direktori Foto Bencana Nyata

Simpan file foto bencana nyata di folder ini dengan nama berikut:

1. `banjir.jpg` - Foto dokumentasi bencana banjir nyata (format JPG, PNG, atau WebP).
2. `tanah-longsor.jpg` - Foto dokumentasi tanah longsor nyata.
3. `kekeringan.jpg` - Foto dokumentasi kekeringan / krisis air nyata.
4. `kebakaran-hutan.jpg` - Foto dokumentasi kebakaran hutan dan lahan (karhutla) nyata.

Sistem akan otomatis memuat file lokal ini jika tersedia!
Jika file belum dimasukkan, aplikasi akan menggunakan foto dokumentasi fallback beresolusi tinggi.
